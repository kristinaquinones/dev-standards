# GTM & Marketing Templates

Reusable templates for go-to-market and marketing activities. Use them in sequence: spec first, then PRD, then brief.

## Workflow templates

Use these in order:

1. [Marketing Spec Template](marketing-spec-template.md) - Lightweight problem/opportunity spec; write this first to define the problem and align on the bet
2. [Marketing PRD Template](marketing-prd-template.md) - Detailed requirements template that builds on the spec
3. [Campaign Brief Template](campaign-brief-template.md) - Comprehensive campaign planning template for directing execution

## Supporting templates

- [Positioning Statement Template](positioning-statement-template.md) - Template for developing positioning statements (used in Campaign Brief)
- [Messaging Hierarchy Template](messaging-hierarchy-template.md) - Template for organizing messaging (used in Campaign Brief)
- [Content Brief Template](content-brief-template.md) - Template for content creation briefs (used in Campaign Brief)
