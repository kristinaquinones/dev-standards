> Write this before the Marketing PRD. The spec defines the problem and the bet. The PRD defines the requirements. The brief directs execution.
>
> This does not need to be long. It needs to be honest and specific.

## The five questions

### 1. Purpose — What outcome are we driving, and what problem are we solving?

[What change are we trying to create? What does success look like at the highest level?]

## AI handoff notes

Use this section when handing this spec to an AI system.

**What this spec is asking for:**

[Describe the task you want the AI to complete based on this spec — for example, "Use this spec to generate a draft Marketing PRD" or "Identify gaps in this spec before I write the PRD."]

**Context to provide alongside this spec:**

- Relevant brand, product, or audience constraints
- Prior performance data if available
- Examples the output should align with or avoid
- Any channel or format requirements

**What the AI should not do:**

- Invent audience insight that is not grounded in the spec
- Expand scope without flagging it as a suggestion
- Substitute generic filler for specific audience understanding
- Skip the measurement section or leave it vague
