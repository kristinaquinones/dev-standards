# GTM & marketing standards - Universal guide

This document serves as an index to comprehensive go-to-market and marketing standards applicable to any product or organization. The standards are organized into discrete files for easier navigation and maintenance.

---

## The workflow

Marketing work follows a three-stage sequence. Each stage has a corresponding document and template.

**Spec → PRD → Brief**

1. **Spec** — Define the problem or opportunity. Align on what you're doing and why before writing requirements. AI works significantly better with a defined spec than a broad prompt.
2. **PRD** — Translate the spec into detailed requirements: full audience definition, scope, constraints, and a complete measurement plan.
3. **Brief** — Turn the PRD into execution direction for teammates, partners, or AI systems.

See the [Marketing Spec](marketing-spec.md) for more on why the order matters and how AI fits in.

## About this document

This index file provides access to all go-to-market and marketing standards, which have been organized into discrete markdown files in this directory. This structure makes the standards easier to navigate, maintain, and reference.

Each section contains detailed guidelines, examples, checklists, and best practices for that particular aspect of go-to-market and marketing. All standards are designed to be:
- **Project-agnostic**: Applicable to any product or organization
- **Universal**: Can be adapted to different industries and team structures
- **Comprehensive**: Cover all aspects of GTM and marketing
- **Maintainable**: Organized for easy updates and cross-referencing
